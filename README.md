# LumixTV

Plataforma de streaming con películas, series, anime y TV en vivo.

## Stack

- Next.js 15 · TypeScript · Tailwind CSS v4
- better-auth · Prisma · Supabase PostgreSQL
- Resend (correo) · TMDB (catálogo)

## Desarrollo

```bash
npm install
cp .env.example .env   # configura variables
npm run dev
```

## Scripts útiles

```bash
npm run build
npm run db:push
npm run admin:promote -- tu@correo.com
```
